## サポート URL & プライバシー URL

GitHub Pages 公開後 (ASC 提出時に必要):
- **Support URL (en/ja)**: `https://<github-username>.github.io/<repo>/support.html`
- **Privacy Policy URL (en/ja)**: `https://<github-username>.github.io/<repo>/privacy.html`

GitHub Pages を有効にする手順:
1. GitHub Web でリポジトリの Settings > Pages へ
2. Source: "Deploy from a branch", Branch: `main`, Folder: `/docs`
3. 数分後 `https://<github-username>.github.io/<repo>/site/` で確認 (folder が `/docs` の場合は `/docs/site/` 配下が公開される)

注: `docs/` 配下が直接公開なら `https://<user>.github.io/<repo>/site/privacy.html`、`/docs/site/` を root に設定するなら `https://<user>.github.io/<repo>/privacy.html` になる。設定確認後に確定。

## スクリーンショット仕様

App Store Connect が要求する解像度:

| デバイス | 解像度 | 言語 | 必要枚数 |
|---|---|---|---|
| iPhone 6.7" / 6.9" (iPhone 17 Pro Max / 15 Pro Max) | 1290×2796 | jp, en | 5枚×2 = 10 |
| iPhone 6.5" (iPhone 11 Pro Max) | 1242×2688 | jp, en | 5枚×2 = 10 (6.7" から派生可) |
| iPad Pro 13" (M5) | 2064×2752 | jp, en | 5枚×2 = 10 |
| iPad Pro 12.9" (3rd-6th gen) | 2048×2732 | jp, en | 5枚×2 = 10 |

合計目安: **8 セット = 40 PNG**。撮影方法:

```bash
# iPhone 17 Pro Max シミュレータで撮影
xcrun simctl boot "iPhone 17 Pro Max"
open -a Simulator
# アプリ起動して必要画面を表示後、Cmd+S で PNG 保存
```

撮影シナリオ (5 枚):
1. **タイトルカット**: ヒーローカード + 「やさしい色で、心ほどける時間。」キャッチコピー焼き込み (1枚目のみ言語別)
2. **塗り絵プレイ中**: PixelBoardView at 中ズーム、パレットトレイ表示、色を塗る瞬間
3. **完成の祝福**: CompletionView の confetti オーバーレイ、章クリア演出
4. **コレクション**: 並んだ完成済みピクセルアート、達成感
5. **デイリーチャレンジ**: Monthly カレンダー、ストリーク表示
